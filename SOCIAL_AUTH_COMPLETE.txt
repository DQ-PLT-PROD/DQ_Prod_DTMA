🚀 SETUP REQUIRED (15 MINUTES)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OPTION 1: Enable Google (Most Popular)
  1. Go to: https://console.cloud.google.com/
  2. Create OAuth Client ID
  3. Add redirect: https://faqystypjlxqvgkhnbyq.supabase.co/auth/v1/callback
  4. Copy Client ID & Secret
  5. Supabase → Authentication → Providers → Google
  6. Paste credentials & Save

OPTION 2: Enable Facebook
  1. Go to: https://developers.facebook.com/
  2. Create app
  3. Add redirect: https://faqystypjlxqvgkhnbyq.supabase.co/auth/v1/callback
  4. Copy App ID & Secret
  5. Supabase → Authentication → Providers → Facebook
  6. Paste credentials & Save

OPTION 3: Enable GitHub
  1. Go to: https://github.com/settings/developers
  2. Create OAuth App
  3. Add callback: https://faqystypjlxqvgkhnbyq.supabase.co/auth/v1/callback
  4. Copy Client ID & Secret
  5. Supabase → Authentication → Providers → GitHub
  6. Paste credentials & Save

💡 TIP: Enable at least Google for best user experience!

🐛 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: "Invalid redirect URI"
  → Check callback URL matches exactly in provider settings

Issue: Social button doesn't work
  → Enable provider in Supabase Dashboard

Issue: Profile not created
  → Check browser console for errors
  → Verify learner_profiles table exists
  → Check RLS policies

Issue: Wrong redirect after login
  → Verify redirectTo URL in signInWithProvider()

See docs/SOCIAL_AUTH_SETUP.md for detailed troubleshooting.
